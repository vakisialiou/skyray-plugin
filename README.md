# 🧩 skyray-plugin

Аддон Blender `skyray` проекта [skyray](../README.md) — читает текущую сцену и отправляет её через [skyray-api](../skyray-api) (обычный HTTP) в открытый проект [skyray-web](../skyray-web) для живого превью. Собран под Blender 5.2.1, только стандартная библиотека Python (`urllib`) — pip внутри Blender не нужен.

## 📦 Что делает

- 📤 Экспортирует объекты как glTF — один маленький `.glb` на объект; иерархия собирается в браузере по `id`/`parentId`. Отправка идёт по одному объекту короткими шагами, Blender не замирает; прогресс — в панели, в строке состояния и в шапке вьюпорта, есть отмена.
- ♻️ Отправляет только то, чего нет в браузере: неизменённые объекты не перепекаются и не экспортируются заново, копии одного меша и общие текстуры уходят один раз.
- 🗜️ Оптимизация для веба (раздел Web Optimization, своя у каждой сцены): предел размера текстур, запеканий и HDRI, WebP вместо PNG, сжатие мешей Meshopt, без объектов, выключенных в рендере.
- 🎨 Материалы Principled BSDF вместе с coat-слоем: процедурные входы запекаются в текстуры (на видеокарте, если она включена в настройках Blender), однотонный результат уходит числом; составные поверхности и Volume приближаются.
- ☀️ Каналы синка, у каждого своя строка и кнопка, плюс Send All: объекты, свет, камера, небо, HDRI, настройки рендера.
- 🖼️ Тестовые и демо-сцены — в соседнем репозитории [skyray-assets](../skyray-assets) (здесь только код аддона).

## 🔧 Установка

1. Собрать zip командой из раздела «Пересборка». В git они не хранятся (`.gitignore`).
2. Blender: Edit → Preferences → Add-ons → Install from Disk… → zip своего сервера → включить аддон:

   | Zip | Имя аддона | Сервер |
   |---|---|---|
   | `skyray-local.zip` | Skyray (local) | локальный api `http://localhost:3500` |
   | `skyray-dev.zip` | Skyray (dev) | `https://dev-gateway.skyray.app` |
   | `skyray-prod.zip` | Skyray | `https://gateway.skyray.app` |

   Все три — один аддон `skyray`, поэтому новый zip заменяет прежний. Имя в списке аддонов и заголовок панели показывают, какая сборка стоит.
3. **После каждой переустановки — полностью перезапустить Blender**: запущенная сессия держит старые модули в кэше. Другая сборка поверх запущенной до перезапуска работает со старым сервером.

## 🔗 Подключение

1. 3D Viewport → сайдбар (`N`) → вкладка "Skyray" → **Connect account**: Blender показывает код и открывает браузер.
2. В браузере (войдя в аккаунт) сверить код и подтвердить подключение. Подключение живёт, пока открыт Blender: токен устройства хранится только в памяти, не в файлах и не в .blend. Закрыли Blender — подключение потеряно и отозвано на сервере, в следующий раз снова **Connect account**.
3. **Choose Project…**: список проектов аккаунта, каждый раз свежий с сервера. Или **New project** (назовётся по .blend-файлу или по сцене). Выбор живёт до Disconnect, закрытия Blender или открытия другого файла; в .blend проект не записывается.
4. **Open in Browser** — открыть проект в веб-приложении. Отправка работает, пока проект открыт хотя бы в одной вкладке браузера.
5. **Selected / All**, затем кнопка в строке канала (Objects, Lights, Camera, Sky, HDRI, Render) или **Send All**. Shift+клик (или **Resend Everything** в Web Optimization) отправляет всё заново, не спрашивая браузер.

Цветная точка в заголовке панели, в строке состояния и на кнопке Skyray в шапке вьюпорта показывает статус: зелёная — готово, жёлтая — нужен шаг, красная — проблема, синяя — идёт отправка, серая — не подключён. Клик по строке состояния или кнопке в шапке открывает ту же карточку. Кнопку в шапке можно скрыть в настройках аддона. Аккаунт и **Disconnect** — в меню у иконки пользователя рядом с проектом. Disconnect отзывает устройство на сервере и забывает проект. Отключить устройство можно и из браузера — аддон заметит это за один heartbeat.

## ⚙️ Пересборка после изменений (обязательно)

```bash
python3 build.py            # три zip в корень репозитория
python3 build.py <папка>    # или в другую папку
```

Весь код аддона — в `src/`, и только он. Каждый zip собирается из неё целиком, внутри это папка `skyray/` — имя аддона в Blender.

Сборки отличаются только именем аддона (`bl_info`) и сервером по умолчанию (`DEFAULT_SERVER_URL` в `src/constants.py`). Исходники — это локальная сборка.

Установленная копия сама не обновляется: без пересборки, переустановки и перезапуска Blender изменения не подхватятся.

## 🌐 Конфигурация

- Сервер выбирается по порядку:
  1. переменная окружения `SKYRAY_SERVER_URL`;
  2. поле **Server URL** в настройках аддона (видно с Developer Extras: Preferences → Interface → Display);
  3. сервер сборки (`DEFAULT_SERVER_URL`).
- Токен устройства хранится только в памяти, на время сеанса Blender. `credentials.json` прежних версий больше не читается.
- `SKYRAY_TOKEN` (headless/CI) используется вместо подключения и при выходе не отзывается. Рецепт headless-запуска — [`CLAUDE.md`](CLAUDE.md).
- Не-локальный сервер требует включённого Online Access (Preferences → System); с localhost аддон работает всегда.
